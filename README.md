# 🔐 Generador de Contraseñas Seguras

[![Screenshot-2025-02-27-110632.png](https://i.postimg.cc/FsS68Mhb/Screenshot-2025-02-27-110632.png)](https://postimg.cc/Wh2SJfFt)

Bienvenido al repositorio del **Generador de Contraseñas Seguras**. Este proyecto está escrito en Python y permite la creación de contraseñas seguras y personalizadas. El objetivo principal es proporcionar una herramienta sencilla pero potente para generar contraseñas robustas que cumplan con los requisitos de seguridad actuales.

## ✨ Características
- **🖥️ Interfaz Interactiva**: Permite al usuario definir las características de la contraseña, como la longitud y la inclusión de letras mayúsculas, minúsculas, dígitos y símbolos.
- **🔎 Clasificación de Fortaleza**: La contraseña generada se clasifica en categorías que van desde "Débil" hasta "Muy Fuerte".
- **💾 Guardado Automático**: La contraseña generada puede ser guardada automáticamente en un archivo de texto en el escritorio del usuario.
- **📋 Copiar al Portapapeles**: Opción de copiar la contraseña al portapapeles para facilitar su uso.
- **🎯 Experiencia de Usuario Fluida**: La interfaz de bienvenida guía al usuario a través del proceso de creación de la contraseña.

## 🛠️ Tecnologías Utilizadas
- **Python 3**: Lenguaje de programación utilizado para desarrollar el generador.

## 📌 Requisitos
- **Python 3.x** debe estar instalado en tu sistema.
